# ⚽ Banco de Dados - Modo Carreira FIFA 21 (SQL)

Este projeto utiliza a linguagem SQL para organizar e analisar o elenco do meu time no Modo Carreira do FIFA 21. É um projeto prático que demonstra como aplicar banco de dados em cenários reais do dia a dia, simulando a gestão técnica e financeira de um clube.

---

## 🛠️ Tecnologias e Conceitos Aplicados
* **Linguagem:** SQL (DDL e DML).
* **Estrutura:** Tabelas normalizadas com chaves primárias (`PRIMARY KEY`).
* **Comandos Usados:** `CREATE TABLE`, `INSERT INTO`, `SELECT`, `WHERE`, `ORDER BY` e funções de agregação.

---

## 📂 Estrutura das Tabelas

O banco de dados divide as informações em duas tabelas para manter a organização:
1. **`jogadores`**: Contém o elenco atual completo (Titulares e Reservas), mapeando dados como nome, posição, overall, idade e nacionalidade.
2. **`historico_vendas`**: Registra as transferências mais marcantes de ex-jogadores que foram vendidos para gigantes europeus (ex: Real Madrid, Bayern).

---

## 🔍 Consultas de Gestão Esportiva (Queries)

No arquivo `elenco_fifa21.sql`, estruturei consultas inteligentes que um técnico usaria para gerenciar o time:
* **Filtro de Elenco**: Separação rápida de jogadores titulares para planejar a tática.
* **Radar de Promessas**: Busca de atletas jovens (sub-23) ordenados pelo potencial técnico.
* **Análise de Mercado**: Relatório de para quais ligas e clubes o time está vendendo mais atletas.
